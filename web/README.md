# Dashboard

Next.js dashboard for the options research harness. It displays the active
shortlist, signal state, risk limits, positions, and trading-loop controls.

## Development

```bash
npm install
npm run dev
```

The development command starts the FastAPI backend on port 8000 and the
dashboard on [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```
